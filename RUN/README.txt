HOW TO RUN THE PROJECT
======================
1. Double-click 1_START_BACKEND.bat
   - First time it installs packages (a few minutes).
   - Wait until you see: Application startup complete
   - Keep that window OPEN.

2. Double-click 2_START_APP.bat
   - First time it sets up the Flutter project (a few minutes).
   - Chrome opens with the app.

To stop: close both black windows.
If a window shows red errors, take a screenshot and send it to Claude.
